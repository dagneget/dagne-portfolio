# Dagnachew Getahun — Portfolio

A dark, editorial developer portfolio inspired by the visual direction of the Soren Hale Framer portfolio. This is an independent Next.js implementation, not a source-code export of the original Framer template.

## Stack
- Next.js 15 / React 19
- TypeScript
- Custom CSS (responsive layouts and styling)
- Framer Motion for entrance and scroll animations
- Lucide icons

## Run locally

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Personalize before publishing

1. Review the project descriptions in `app/page.tsx`. Each project currently links to the general GitHub profile; replace those URLs with the specific repository/demo links when available.
2. Add a real portrait in `public/` if desired, and update the hero in `app/page.tsx`.
3. Verify the contact email and social links.
4. Update `metadataBase` in `app/layout.tsx` to the real domain after deployment.
5. Add a CV PDF to `public/` and add a download link if you want a résumé download button.
6. Confirm that each listed tool represents your current level of experience before publishing.

## Accuracy notes
- Project descriptions are intentionally cautious and do not claim unverified metrics or production usage.
- The project links currently point to the GitHub profile because individual repository URLs were not supplied.
- No employer history or testimonials have been fabricated.
